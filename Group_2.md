# 💰 Proyecto: Sistema de Control de Gastos Personales

## 📌 Descripción

Aplicación en consola para registrar ingresos y gastos mensuales, calcular balance y administrar movimientos financieros.

---

## 🎯 Objetivos

Aplicar fundamentos de Python junto con trabajo colaborativo usando Scrum y Git.

---

## 🧩 Funcionalidades

* Registrar ingreso
* Registrar gasto
* Listar movimientos
* Editar movimiento
* Eliminar movimiento
* Mostrar balance total

---

## 🧠 Requisitos Técnicos

* Validar que montos sean numéricos y positivos
* Manejo de errores si el usuario ingresa texto inválido
* Uso de `try/except`
* Modularización del código
* Menú interactivo

---

## 📂 Estructura

```
project/

│  ├─ menu.py
```

## 🏃 Metodología

* 2 sprints
